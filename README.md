# FRchat

Рабочая лента для собственников франшизы «Домиан»: сообщения, события, сроки, файлы и архив.

Основной адрес пилота: [lesauteur.github.io/FRchat](https://lesauteur.github.io/FRchat/).

Пилот содержит 46 реальных публикаций за 15.09–15.10.2026, зашифрованных в браузерном формате AES-GCM. Код доступа выдаётся участникам отдельно и не хранится в репозитории. Реализованы лента, карточки, календарь месяца/недели, повестка, поиск, фильтры, архив и ссылка на задачу дня. Редактор публикаций — следующая веха.

## Запуск локально

Нужен Node.js 24+:

```powershell
npm ci
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

Открыть `http://127.0.0.1:4173/`. В репозитории уже есть зашифрованный набор пилота, поэтому CI и локальная сборка не требуют исходной выгрузки или кода доступа. Доступ к карточкам после сборки по-прежнему требует кода.

На исходном рабочем компьютере код находится только в `.local/pilot-access-code.txt`. Исходная выгрузка, seed, документы постановки с примерами из чата и скриншоты находятся локально и исключены из Git. Команда `npm run pilot:data` предназначена для пересборки данных на этом компьютере; на чистом клоне без samples её запускать не требуется.

## Проверки

```powershell
npm run check:repo
npm test
npm run build
```

Дополнительно на рабочем компьютере с локальными материалами: `npm run test:pilot` и `npm run test:browser` при работающем preview. Скриншоты содержат реальные сообщения и сохраняются только в `.local/`.

## Публикация

PR проходит QA, а merge в `main` запускает `.github/workflows/pages.yml`: повторные проверки, сборка `dist` и деплой GitHub Pages. В Pages выбран источник GitHub Actions. Публикуется только `dist`, в котором нет исходной выгрузки и кода доступа.

Для кода применяется установленный процесс: отдельная ветка → push → PR → зелёные проверки → merge → fast-forward локальной main → ожидание Pages deploy. Прямой push кода в main не используется.

Для пилота шифротекст хранится в `public/pilot-data/` рядом с приложением. Формат совместим с будущим отдельным data-репозиторием: `manifest.json` + `objects/<sha256>.bin`. Чтение идёт с того же Pages, без GitHub API и домена raw. Данные никогда не расшифровываются в CI.
