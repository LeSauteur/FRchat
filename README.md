# FRchat

Рабочая лента для собственников франшизы «Домиан»: сообщения, события, сроки, файлы, архив, избранное и справочник.

Основной адрес пилота: [lesauteur.github.io/FRchat](https://lesauteur.github.io/FRchat/).

Стартовый набор пилота содержит 46 реальных публикаций за 15.09–15.10.2026, зашифрованных AES-GCM. Актуальное наполнение пополняется в FRchat-data; встроенная копия остаётся резервом. Редактор для руководителя: вставить сообщение → проверить → опубликовать. Есть отдельные доступы admin и user1–user5, лента, карточки, календарь, поиск, архив, избранное, справочник и ссылка на задачу дня. Пароли выдаются отдельно и не хранятся в репозитории.

## Запуск локально

Нужен Node.js 24+:

```powershell
npm ci
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

Открыть `http://127.0.0.1:4173/`. В репозитории уже есть зашифрованный набор пилота, поэтому CI и локальная сборка не требуют исходной выгрузки или кода доступа. Доступ к карточкам после сборки по-прежнему требует кода.

На исходном рабочем компьютере пароли находятся в `.local/PILOT_PASSWORDS.md` с полем «Кому выдан». Исходная выгрузка, seed, документы с примерами из чата и реальные скриншоты исключены из Git. Старый `npm run pilot:data` блокируется для рабочих данных с отдельными доступами. Отзыв одного пользователя и подключение публикации описаны в [инструкции админки](docs/ADMIN_PILOT.md).

## Проверки

Поиск из любого раздела охватывает актуальное, архив и справочник, группируя результаты. Рабочая лента сортируется по последней публикации или напоминанию; техническая правка не поднимает карточку. Категории справочника вынесены из фильтров ленты. Задача дня читает темы и стабильные идентификаторы действий из `https://lesauteur.github.io/domian-7-days/data/days.json`; отметки показываются только за сегодня и при совпадении версии контента.

```powershell
npm run check:repo
npm test
npm run build
```

Дополнительно на рабочем компьютере с локальными материалами: `npm run test:pilot` и `npm run test:browser` при работающем preview. Скриншоты содержат реальные сообщения и сохраняются только в `.local/`.

`npm run test:themes` при работающем preview проверяет обе системные схемы и ручные переключения на 390/1280 px, контраст и новые функции на искусственных данных. `-- --start-server` запускает собственный preview для CI. Публичные скриншоты и отчёт — в `docs/qa/`.

## Публикация

PR проходит QA, а merge в `main` запускает `.github/workflows/pages.yml`: повторные проверки, сборка `dist` и деплой GitHub Pages. В Pages выбран источник GitHub Actions. Публикуется только `dist`, в котором нет исходной выгрузки и кода доступа.

Для кода применяется установленный процесс: отдельная ветка → push → PR → зелёные проверки → merge → fast-forward локальной main → ожидание Pages deploy. Прямой push кода в main не используется.

Рабочий шифротекст хранится в публичном [FRchat-data](https://github.com/LeSauteur/FRchat-data). Текущий ref определяется одним публичным запросом, затем manifest и объекты читаются с raw по неизменному SHA коммита, без токена читателя. `public/pilot-data/` — резервная копия. Запись приложения идёт одним атомарным Git Data API коммитом. Токен зашифрован под длинным паролем admin; один раз его настраивает Алексей. CI использует только искусственные данные и не расшифровывает пилот.
