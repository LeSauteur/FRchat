# Избранное и справочник

Звёздочка доступна в списке и в полной карточке. «Избранное» показывает сохранённые записи независимо от архива. В поиске есть фильтр «Только избранное», сохраняемый в URL (`favorites=1`). Нижняя и боковая навигация включают оба новых раздела.

Ключ `frchat.favorites.v1` в localStorage содержит только массив уникальных ID. Чтение и запись защищены try/catch; при запрете записи закладки работают в памяти вкладки с предупреждением. Изменения синхронизируются между вкладками через событие storage. Выход забывает код доступа, но сохраняет закладки. Очистка данных браузера удалит их; другой браузер, устройство или MAX WebView имеет своё хранилище.

Архивная запись остаётся полноценной карточкой со статусом. Если данные содержат `state: "deleted"`, избранное показывает её с пометкой «Удалено»; обычная лента и архив её не показывают. Если ID полностью исчез из набора данных, остаётся карточка «Публикация удалена» со звёздочкой для удаления закладки. Название и текст не кэшируются открытым текстом, поэтому восстановить название полностью удалённой записи на этом устройстве нельзя. Поиск по её прежнему тексту также недоступен.

## Наполнение справочника через seed

В пилоте пока нет справочных записей. Пустое состояние сообщает, что Алексей готовит материалы. Категории заданы отдельно от рабочих сообщений:

| category_id | Категория |
| --- | --- |
| reference-payments | Оплаты и взносы |
| reference-details | Реквизиты и почты |
| reference-contacts | Контакты — техподдержка, банки, партнёры |
| reference-offices | Офисы и территории |
| reference-instructions | Инструкции |

Согласованный формат: отдельный массив `references` в `frchat-seed/1`. Импорт присваивает этим записям `type: "reference"`. Допустим и этот тип непосредственно в `posts`. ID уникален во всём наборе и остаётся тем же при исправлениях, чтобы сохранить закладки и ссылки.

Пример для генератора seed (только искусственные сведения):

```json
{
  "id": "reference-support",
  "category_id": "reference-contacts",
  "title": "Контакты поддержки",
  "body": "Согласованные контакты техподдержки.",
  "source": "Администрация",
  "author": { "id": "admin", "display_name": "Администратор" },
  "priority": "normal",
  "pinned": false,
  "state": "active",
  "created_at": "2026-10-15T12:00:00+03:00",
  "updated_at": "2026-10-15T12:00:00+03:00",
  "dates": [],
  "links": [],
  "attachments": [],
  "expected_attachments": [],
  "history": [],
  "reminded_at": [],
  "related": []
}
```

Исправления вносятся в локальный генератор, а не вручную в сгенерированный seed. Далее штатные `npm run pilot:data`, `npm run test:pilot`, `npm run build`. Справочные записи попадают в те же зашифрованные месячные объекты и общий индекс; открытых JSON с их текстом нет. Исходные материалы и код остаются вне Git. Не добавляйте пример выше в настоящий пилот вместо материалов Алексея.

Тип `reference` не архивируется по `dates` или `expires_at`, не попадает в «Горит», рабочую ленту без поиска, архив и календарь. Для удаления используется `state: "deleted"`. В любом разделе текстовый поиск охватывает актуальное, архив и справочник; результаты разделены на эти три группы. Учитываются отдельные слова, «е/ё» и обычные русские окончания. Явно выбранные фильтры, включая «Только избранное», продолжают действовать. Пять категорий справочника доступны только в его разделе без поискового запроса; в фильтрах рабочей ленты их нет. Справочную карточку также можно добавить в избранное.

Проверки: unit-тесты хранения, импорта и правил архивации; браузерные сценарии в обеих схемах (звёздочки, перезагрузка, архив, удаление, фильтр, общий поиск, категории и запрет storage); аудит контраста и снимки справочника с данными и без них — в `docs/qa/`.

В справочник перенесён отдельный блок «Шаблоны и файлы», доступный по видимой ссылке в начале раздела. В нём собраны вложения актуальных и архивных сообщений; удалённые публикации исключены. Категории постоянной информации не скрывают этот общий каталог. В навигации пять разделов без дополнительного меню, старый адрес `#/files` также открывает справочник. Подробности: [читаемость и навигация](MOBILE_READABILITY.md).
