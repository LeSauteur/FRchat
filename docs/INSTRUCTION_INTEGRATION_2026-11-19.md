# FRchat и инструкция франшизы

19 ноября 2026. Локальная версия на основе действующего FRchat. Изменения не отправлены и не опубликованы.

## Что получает участник

Во вкладке «Документы» рядом с существующими материалами появились 12 разделов вчерашней инструкции. Быстрые переходы ведут на регистрацию сотрудника, контакты, группы MAX и офисы сети. Статьи открываются внутри FRchat с прежней навигацией и темой. Категории и оба поиска охватывают добавленные материалы.

- Регистрация: полный комплект документов, сроки до 16:00 / 16:00–18:00, чек-лист, копируемая шапка и реквизиты СБ. Отметки не сохраняются и не собирают данные кандидата.
- Контакты: 19 записей, поиск по имени, роли и телефону; отдельная публичная страница для отправки агентам сохранена.
- MAX: 43 группы, фильтры категорий и поиск.
- Офисы: 68 действующих офисов, поиск по названию, адресу, собственнику и телефону, отдельная группа офисов Павла Орлова. «Шахты» не смешиваются с «Каменском-Шахтинским» при поиске офиса.
- Анкета и офферы: три локальных файла в сборке, побайтово совпадающие с утверждённой инструкцией. Ставка передачи агентов — 2,5% с оборота сделки.

Используются существующие категории документов, маршруты и поиск FRchat. Переходы `#/reference`, `#/files`, старые карточки новостей и документы остаются рабочими. Новые маршруты имеют вид `#/documents/instruction/registration`.

## Источник и обновление

Встроена опубликованная версия [Instrukciya](https://github.com/LeSauteur/Instrukciya) `4d3f9323526fe7938e4bcf21a70134398a18db63`. Это явный снимок версии, а не незаметная загрузка изменяемого внешнего сайта. FRchat не исполняет исходный HTML: в React передаются текст и разрешённые структурные элементы. Внешние скрипты, стили, изображения, iframe и обработчики событий не импортируются.

Скрипт `scripts/import-instruction.py` читает чистую копию канонического репозитория и требует, чтобы коммит входил в `origin/main`. Он заново формирует JSON и копирует три документа с их хэшами:

```powershell
python scripts/import-instruction.py --source C:\путь\к\Instrukciya
npm test
npm run build
npm run test:instruction
```

Python 3 нужен только при обновлении импорта. Сам FRchat и его сборка остаются на существующем Node.js / React / Vite, новых npm-зависимостей нет. Изменение количества разделов или справочников требует проверки импорта и тестов.

В этой версии встроенные статьи обновляются через источник и повторный импорт. Существующая админка по-прежнему создаёт и редактирует собственные зашифрованные документы FRchat. Встроенная инструкция не выдаётся за редактируемую запись рабочего хранилища.

## Рабочие данные и доступы

FRchat-data, шифротекст, пароли, ключи хранения, роли и формат снимков не менялись. Инструкция не создаёт фиктивные новости, события или непрочитанные публикации. Существующие данные не мигрируются и не копируются в открытый JSON.

Импортирован только уже опубликованный текст, контакты, группы, сокращённый адресный справочник и три пустых бланка. Эти материалы остаются публичными в статической сборке; экран входа FRchat не объявляется новой защитой уже открытой инструкции. Закрытые документы FRchat продолжают использовать существующее зашифрованное скачивание.

## Просмотр

Сборка проверяется в отдельном локальном контуре на учебных новостях и входах. Встроенная инструкция — настоящая опубликованная версия от 18 ноября. Этот контур не отправляет данные в GitHub и не меняет рабочие публикации.

```powershell
npm run build
$env:FRCHAT_PREVIEW_PORT='4191'
npm run preview:workspace
```

Адрес: http://127.0.0.1:4191/. Учебный вход: `user1` / `qa-reader-password-only`. Эти данные не подходят для рабочего FRchat. Основная копия проекта C:\Domian\FRchat и опубликованный сайт не переключались на эту версию.

## Проверки

Базовые проверки: `npm ci`, `npm run check:repo`, `npm test`, `npm run build`. Браузерные проверки существующей оболочки: `npm run test:themes -- --start-server` и `npm run test:workspace`. Дополнительно `npm run test:instruction` проверяет все 12 разделов на 390 / 430 / 1280 px в двух темах, общий поиск, фильтры, копирование, три скачивания с проверкой SHA256, старые маршруты и отсутствие ошибок страницы. Для локальных результатов задаётся `FRCHAT_QA_OUTPUT`, чтобы не перезаписывать исторические снимки.

Публикация — отдельная ветка, push в origin, PR, зелёный QA, merge, ожидание Pages и проверка опубликованного сайта по прямому поручению владельца.

### Результаты локальной проверки

- `npm ci` — успешно; npm-зависимости не менялись.
- `npm run check:repo` — проверены 357 файлов, приватных исходников и известных секретов не найдено.
- `npm test` — 56 из 56 успешно, включая существующие тесты шифрования, писателя, отзыва доступа, новостей и документов.
- `npm run build` — TypeScript и Vite успешно; контейнеры и хэши 10 зашифрованных объектов сохранены, проверка приватности сборки прошла.
- `npm run test:themes -- --start-server` — 108 проверок тем, 54 снимка, нарушений контраста нет. Дополнительно прошли сценарии сроков, напоминаний, админки, повторов, избранного и старого справочника.
- `npm run test:workspace` — 46 проверок контраста и расположения элементов, административные сценарии и прежние маршруты сохранены.
- `npm run test:instruction` — 72 проверки всех разделов на 390 / 430 / 1280 px в светлой и тёмной темах; фильтры, чек-лист, буфер обмена и три скачивания с SHA256 прошли. Переход из поиска сразу применяет запрос к контактам, группам или офисам. Отдельно проверены пустые результаты, неизвестный раздел и возврат через старые маршруты.
- В браузере вручную проверены регистрация, копирование, офисы Шахт и переходы из общего поиска к Лилекиной и ЖК Иловайский. Ошибок и предупреждений консоли в этих сценариях нет.

Результаты и снимки находятся локально в `.local/qa/instruction-20261119/`. Их учебные новости и входы не относятся к рабочему FRchat. Изменений в `public/pilot-data` и модулях `crypto`, `storage`, `writer`, `access-rotation`, `admin-session` нет; исходная рабочая папка FRchat осталась чистой.
