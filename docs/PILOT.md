## Запуск

Нужен Node.js 24+. В PowerShell из `C:\Domian\FRchat`:

```powershell
npm ci
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

Открыть `http://127.0.0.1:4173/`. Это адрес текущего компьютера, он не доступен другим тестировщикам через интернет. Для телефона используйте опубликованный HTTPS-адрес; WebCrypto обычно недоступен на обычном HTTP-адресе локальной сети. localhost считается доверенным контекстом для локальной разработки.

Код доступа автоматически создаётся в `.local/pilot-access-code.txt`. Откройте этот файл локально и передайте код участникам отдельно. Скрипт не выводит его в терминал; команда не принимает секрет в аргументах. При повторной сборке используется существующий код. Не отправляйте этот файл в Git, чат или вместе с артефактом приложения.

В репозитории хранится уже зашифрованный набор пилота. Обычная сборка и CI используют его без исходного seed и кода доступа. `npm run pilot:data` нужен только при обновлении исходных материалов на рабочем компьютере. После пересборки проверенные изменения шифротекста включаются в PR.

## Что хранится где

- `samples/` — исходная выгрузка, seed, генератор, заметки и файлы; только локально.
- `.local/` — код, зашифрованный результат, отчёты, снимки экрана; исключено из Git.
- `public/pilot-data/` — сгенерированные manifest и зашифрованные объекты; включены в Git для публикации пилота. Только содержимое этого каталога переносится в dist, исходный seed туда не копируется.
- `public/config.json` — публичные URL источников, обратной связи и 7 days; без секретов.
- `dist/` — собранное приложение плюс шифротекст; не коммитится.

Ссылки в приложении работают через hash: `#/post/<id>`, `#/calendar`, `#/archive`. Фильтры сохраняются в URL. При открытии карточки код нужен до расшифровки её названия и текста. Поиск с главной охватывает также архив; внутри архива ищет по архиву. Все три месячных блока загружаются при входе, частичных результатов поиска нет.

Для разработки `npm run dev`. Приватные папки заблокированы настройкой Vite; production preview обслуживает только dist.

## Исправление и добавление материалов

Seed руками не менять. Сначала исправить `samples/seed/build_seed.py`, затем выполнить его установленным Python 3 с UTF-8. В данном окружении Windows alias `python` не работает; встроенный интерпретатор Codex запускается так:

```powershell
& 'C:\Users\domia\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -X utf8 -B samples/seed/build_seed.py
```

Потом повторить `npm run pilot:data`, `npm run build`, `npm run test:pilot`. Указанный путь относится к текущему компьютеру; на другом достаточно установленного Python 3.

Пять ожидаемых Excel обозначены «Файл будет добавлен». Для реальных вложений создать `samples/seed/files/`, положить туда документы и `attachments.json`:

```json
[
  {
    "post_id": "id-нужной-карточки-из-seed",
    "file": "template.xlsx",
    "expected_label": "точная подпись ожидаемого файла из seed",
    "permanent_template": true
  }
]
```

Имя файла может быть русским. Привязка явная, без угадывания по именам. Файлы вне указанной папки запрещены; лимит — 25 MiB. Исходное имя и хэш находятся в зашифрованных метаданных; файл на диске хранилища называется по хэшу шифротекста. Пользователь скачивает расшифрованные байты с исходным именем.

Не подтверждены: версия расписания на 7 октября; пять Excel; ссылки на два уже прошедших онлайн-события; новый срок рефералов. Неизвестные сведения не додуманы. Телефон для чека исправлен в генераторе по ответу пользователя. Служебные review_notes и origin_message_ids отсутствуют в читательском хранилище.

## Настройки

`feedbackUrl` в `public/config.json` — адрес MAX или формы, который пользователь выберет для отзывов. Пока он пустой, кнопка открывает окно составления и копирования отзыва; отправки нет.

`dataSources` — упорядоченный список базовых URL с завершающим `/`. Сейчас `./pilot-data/`. В дальнейшем можно указать raw, Pages data-репозитория и проверенный CDN для неизменяемых объектов; ни один резервный адрес пока не включён. Каждый источник обязан отдавать тот же объект с указанным SHA-256. Установите реальные разрешённые источники в CSP при изменении доменов. Не направляйте manifest на CDN без определённой версии данных.

`dailyTaskUrl` — предполагаемый JSON 7 days. Пока он отсутствует, показывается ссылка на настоящий чек-лист московского дня. Темы и promise не имитируются, чужой JavaScript не исполняется. Для экспорта JSON из domian-7-days требуется разрешение и отдельный PR. Прогресс из `domian:calendar:v3` читается только на том же origin и при совместимой версии данных; в localhost прогресс опубликованного сайта недоступен.

## Проверка

```powershell
npm test
npm run test:pilot
npm run build
# Preview должен быть запущен на 4173; нужен Edge на Windows или Chromium Playwright на другой ОС:
npm run test:browser
```

Перед сборкой проверяются хэши, контейнеры и уникальность IV всех публичных объектов. `npm run check:repo` проверяет индекс Git на приватные файлы и известные локальные секреты. Unit-тесты используют только синтетические данные. `test:pilot` проверяет весь локальный seed и хранит только локальный отчёт. Скриншоты браузерной проверки содержат реальные данные: `.local/browser/`, не коммитить и не включать в CI-артефакты. Проверка приватности сборки ищет реальные заголовки/имена из локального seed и шаблоны токенов; CI без seed выполняет общую проверку структуры/секретов.

Перед реальным использованием человек должен проверить MAX WebView Android/iOS, запоминание кода, установку иконки, мобильные сети и офисный Wi-Fi без VPN. Локальный тест Edge этого не подтверждает.

## Доступ и ограничения

Код хранится в localStorage только при выбранном «Запомнить». Ключ остаётся в памяти. «Забыть код и выйти» убирает локальный код и читательскую сессию. Кнопки обратной связи и установки доступны с телефона. Данные при отсутствии сети не обещают работать офлайн; service worker не используется.

У всех сайтов на `lesauteur.github.io` общий origin. Не добавлять ни на один из них Яндекс.Метрику, стороннюю аналитику, CDN-скрипты или виджеты: они способны читать сохранённый код. При необходимости такой интеграции FRchat нужно вынести на отдельный origin. Meta CSP на Pages не даёт защиты frame-ancestors.

Общий код не обеспечивает персональный отзыв доступа. Старые коммиты и скачанные копии не отзываются сменой кода. История репозитория растёт; сжатие отложено и никакого переписывания истории приложение не выполняет.

## Публикация

Пилот публикуется в созданный пользователем `LeSauteur/FRchat`, remote origin указывает на этот репозиторий. Соседние проекты не меняются. `.github/workflows/pages.yml` собирает и публикует только dist после merge в main. Применяются глобальные правила пользователя: отдельная ветка, push, PR, зелёный QA, merge, fast-forward main и ожидание нужного Pages deploy. Не использовать Sites, временные Git-серверы, ручные Authorization-заголовки в командах или push в main.
