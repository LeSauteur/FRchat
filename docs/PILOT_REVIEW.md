# Пилот FRchat — пакет для внешней проверки

15.10.2026. Первичная проверка выполнена в ветке `pilot-reader` до публикации. После прямого поручения пользователя эта же веха публикуется через PR/QA/Pages; актуальная инструкция — в `docs/PILOT.md`. Соседние проекты не изменены.

## Что готово

46 реальных карточек из предоставленного seed; воспроизведены тексты, категории, даты, история, связи и напоминания. Код доступа и ключи не встроены в приложение. AES-GCM-контейнер, PBKDF2-SHA-256 600 000, один ключ в памяти на сессию. Индекс и три месячных блока шифруются Node-скриптом и читаются браузером. Исходники и секреты не обслуживаются preview и исключены из Git.

Лента с закреплённым/«Горит»/мотивацией, карточка с историей, архив, поиск с ё=е, категории и дополнительные фильтры в URL, календарь месяца/недели, повестка 14 дней, ряд дней рождения, отметка прочитанного, светлая/тёмная тема, файлы с честными ожиданиями, копирование ссылки и отзывов. Иконки для установки на телефон. Постоянная плашка о дате данных пилота.

Задача дня открывает настоящий чек-лист 7 days для текущего московского дня. Внешний JSON ещё не создан; темы не выдумываются, исходный days.js не исполняется. Код domian-7-days не изменён.

## Что проверено автоматически

- 9 unit-тестов: бинарный round-trip, неверный код, повреждение, AAD, новый IV, стоимость KDF; МСК, границы 24 часов и двух часов, несколько сеансов, all-day дедлайн, повтор/исключение/недельная ссылка; поиск и диапазоны; удаление служебных полей seed.
- Полная расшифровка локального пилота: 46 id, тексты и даты совпадают с импортом seed; четыре ссылки по экземплярам; 55 календарных записей в окне 15.09–01.11. Seed и исходные сообщения в CI не нужны.
- TypeScript, production build и проверка 14 файлов dist: открытые заголовки/имена из seed и токены отсутствуют.
- Edge через Playwright: отказ неверному коду, успешное открытие реальных данных, прямые ссылки и повторный вход, архив/поиск/URL, сентябрь и октябрь календаря, неделя/повестка, ширины 360/390/768 без переполнения, тёмная тема, пять ожиданий файлов, выход с очисткой кода, отсутствие выдачи приватных файлов сервером и необработанных исключений.

Снимки экрана и отчёты только в `.local/`, потому что содержат настоящие публикации. Инструкция: `docs/PILOT.md`. Актуальный сокращённый план: `docs/DEVELOPMENT_PLAN.md`.

## Что проверить Claude

1. Криптографический формат и привязку заголовка через AAD; строгий ref по хэшу; отсутствие plaintext/секретов в dist и приватных папок на dev/preview.
2. Интерпретацию seed: ссылки по неделям, конечные границы all-day, последние сеансы, закрытые/перенесённые карточки и архив по реальному времени.
3. Полноту локального поиска, устойчивость URL, читаемость мобильного интерфейса и поведение при отсутствующих файлах/внешнем JSON.
4. Соответствие новой границе работ: в пилоте нет редактора, PAT, Git Data API записи и публикации.

## Что остаётся до раздачи участникам

- Подтвердить расписание курса на 7 октября. Телефон уже исправлен в генераторе по ответу пользователя.
- Добавить пять Excel, если они доступны, через `samples/seed/files/attachments.json`; при отсутствии видна подпись «Файл будет добавлен».
- Две отсутствующие ссылки остаются отсутствующими. Для рефералов новый срок не назначен: действует известная история.
- Указать выбранный канал обратной связи в config, если нужен прямой переход; пока работает копирование отзыва.
- Проверить реальными телефонами MAX Android/iOS, запоминание кода и установку иконки; реальными мобильными сетями и Wi-Fi — доступ без VPN. Автоматизированный локальный Edge этого не доказывает.
