# Напоминания без копий карточек

В «Ваших публикациях» и на полной карточке администратора есть «Напомнить». Обычный дубль в редакторе предлагает ту же функцию, с той же формой и записью. Будущие сроки перечислены по московскому времени, ближайший выбран заранее. Истёкшие сроки не выбираются; законченные, удалённые, отменённые, перенесённые и справочные карточки не возобновляются напоминанием. Если сроков нет, выбора нет: подпись использует ближайшее событие, либо остаётся общей для публикации без дат.

Запись `reminded_at[]` сохраняет идентификатор операции, время, автора, идентификатор выбранной даты, вид, подпись и снимок её начала/окончания/признака «до конца дня»; для серии сохраняется день экземпляра. Старые записи без дополнительных полей остаются совместимыми. В админке есть «Напоминали N раз» и раскрываемая история. Если о той же карточке уже напоминали менее 12 часов назад, показано предупреждение с количеством часов; повтор требует отдельной отметки подтверждения, даже если выбран другой срок.

Ручное напоминание сохраняет существующий id и содержимое, обновляет `updated_at`, поэтому все участники после загрузки обновления снова видят публикацию непрочитанной и получают её в счётчик новых. Просмотр карточки отмечает её прочитанной обычным образом. На сутки она переносится в верхний блок «Напомнили участникам», получает рамку и подпись срока. Во всех остальных блоках эта карточка исключается: экземпляр остаётся один. Исправление текста не создаёт записи напоминания и не меняет дату последнего напоминания; счётчик «Изменено» исключает записи `created`/`reminded`.

Подтверждение защищено от двойного нажатия; повтор запроса использует тот же id операции и не создаёт вторую запись. Публикация с постом/месяцем/индексом сохраняется атомарно прежним Git Data writer. Изменение карточки другим администратором требует повторной проверки свежей версии, без затирки текста. Ошибки сети не закрывают форму. Это напоминания внутри FRchat, без фоновой рассылки или push на телефоны.

При дубле исходный текст и файлы продолжают храниться в зашифрованном черновике после отправки напоминания и после ухода на главную. При следующем создании можно продолжить черновик. Перед напоминанием проверяется успешное сохранение черновика. Дописывание объединяет оба текста, оставляя исправление отдельных дат на явную проверку администратора. Серии сохраняют отдельный сценарий изменения ссылки/времени конкретной встречи.

После успеха «Скопировать для MAX» формирует заголовок, выбранный срок и прямую ссылку `#/post/<id>`. При отказе в доступе к буферу появляется поле для ручного копирования. В чистом браузере маршрут сохраняется при вводе пароля и открывает именно эту карточку.

Проверки: `tests/reminders.test.mjs` (снимок срока, границы 12/24 часов, исключение истёкших дат, события без выбора, дописывание, атомарный повтор при потере ответа), `scripts/reminder-qa.mjs` (две темы, 390/430/1280 px, устройство America/Los_Angeles, контраст, два читателя и счётчики новых, одиночная поднятая карточка, сеть, двойное нажатие, предупреждение, чистый браузер по скопированной ссылке, сохранность черновика и файла после дубля). Искусственные снимки — `docs/qa/*-reminder-*.png`, отчёт — `docs/qa/reminder-report.json`. Секреты и реальные сообщения в публичные артефакты не входят.
