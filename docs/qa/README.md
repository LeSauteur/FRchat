Реальный ограниченный токен проверен отдельно: самостоятельный вход admin в новом сеансе, публикация настоящего сообщения, чтение новым user1 без токена и удаление через интерфейс. Для обнаруженного повтора — 4 нажатия, около 11 секунд автоматизации. Реальные снимки и результат сохранены только в `.local/admin-real/`; это не измерение времени неподготовленного руководителя.

Причина ошибки: `:root` задавал постоянный тёмный цвет текста и светлый фон, хотя карточки уже использовали переменные тёмной схемы. Теперь корень и `body` используют `--text` и `--bg`. Статусы, категории, файлы, ссылки и полупрозрачные подложки получили отдельные значения для обеих тем. SVG используют `currentColor`.

`npm run test:themes` проверяет вход, ленту, карточку, календарь, архив, поиск, избранное и справочник с данными и без них на ширинах 390 и 1280 px. Для каждой ширины проверяются системные light/dark и оба ручных переопределения темы, включая переключение настоящей кнопкой и сохранение выбора. Всего 72 случая; горизонтального переполнения и ошибок приложения нет. Отдельные сценарии в том же запуске проверяют звёздочки, перезагрузку, архивные и удалённые закладки, фильтр поиска, категории справочника и запрещённый localStorage в обеих схемах.

Контраст: axe-core `color-contrast` — 0 нарушений. Дополнительная проверка текста, полей и иконок учитывает прозрачность и все комбинации крайних цветов градиентов, требуя 4,5:1 даже для крупного текста. Она дополняет случаи, которые axe оставляет для ручной проверки. Минимум — **4,682:1**. Полные результаты: [contrast-report.json](contrast-report.json). Проверка исходного CSS воспроизводит 9 ошибок с минимумом 1,013:1: [baseline-regression.json](baseline-regression.json), [скриншот до исправления](390-before-dark-login.png).

Все 36 актуальных скриншотов в этой папке используют **искусственные зашифрованные данные**, без сообщений группы и кода пилота. Формат имени: `<390|1280>-<light|dark>-<login|feed|post|calendar|archive|search|favorites|reference|reference-empty>.png`. Например: [мобильная светлая лента](390-light-feed.png), [мобильная тёмная лента](390-dark-feed.png), [тёмное избранное](390-dark-favorites.png), [пустой справочник](390-light-reference-empty.png).

`npm run test:browser` дополнительно выполняет по 14 функциональных проверок в каждой системной схеме на настоящих данных пилота, включая ручное переключение темы, избранное и пустой справочник. Его скриншоты сохраняются только в исключённой из Git `.local/`. Это эмуляция мобильного viewport, а не проверка физического телефона или встроенного браузера MAX.

## Отличия мобильной главной от концепта

- Шапка содержит FRchat, отметку пилота, переключатель темы и выход; заголовок «Актуально» вынесен ниже. В концепте шапка компактнее и содержит дату и уведомления.
- Блок задачи дня выше. Пока нет интеграции с JSON «7 дней», показана честная ссылка на приложение и копирование объявления; конкретная тема и прогресс из концепта отсутствуют.
- Поиск и прокручиваемые категории постоянно видны над лентой. В концепте поиск свёрнут в иконку, поэтому больше карточек помещается сразу.
- Карточки содержат выдержку текста, статус, даты и отметку прочтения; они выше компактных карточек концепта. Роялти представлены обычной выделенной карточкой, а не отдельной узкой плашкой.
- Отдельного компактного списка «Ближайшее» на главной нет; события доступны в календаре и повестке.
- Часть подписей и меток мельче, чем в концепте. Контраст исправлен; переработка плотности и типографики в этот PR не входит.
- Сохранены красный акцент, синий блок задачи, тёплый светлый фон, скруглённые карточки и нижняя навигация. После отзыва пилота в навигации шесть разделов вместо четырёх; в карточках появились звёздочки.
